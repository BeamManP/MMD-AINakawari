# AIナカワリ 0.3.0 の計測メモ（2026-11-10）

0.3.0（NVIDIA 以外の GPU への対応・生成の中断・セットアップの直し）を作った時に測った数字です。
別のセッション・記事・告知で使う時は、**「測った PC は 1 台だけ」という条件ごと**持っていってください。

## 測った PC（これ 1 台だけ）

| | |
|---|---|
| GPU | NVIDIA GeForce RTX 3090（VRAM 24GB） |
| CPU | Intel Core i7-12700F（12 コア・20 スレッド） |
| メモリ | 64GB |
| OS | Windows 11 |
| 部品の版 | PyTorch 2.11.0+cu128・ONNX Runtime（DirectML）1.23.0（Kimodo の環境）／1.24.4（MotionBricks の環境）・TensorRT 10.8.0.43・Warp 1.17.0 |

**別のグラボ（AMD の Radeon・Intel の Arc や内蔵・GTX 10 シリーズ）では 1 回も動かしていません。**
下の「DirectML」は RTX 3090 を DirectML 経由で動かした値、「GPU なし」は同じ PC で GPU を隠して CPU だけで動かした値です。

## 速さ

### Kimodo（プロンプトで作る。ノイズ除去 100 回）

| 方式 | 2 秒の動き（67 フレーム・キー 9 個） | 10 秒の動き（300 フレーム・キーなし） | 備考 |
|---|---|---|---|
| CUDA（PyTorch。0.2.x までと同じ） | 3.1〜3.4 秒 | 7.4 秒 | |
| DirectML（ONNX Runtime） | 3.2〜3.3 秒 | 7.2 秒 | 新しい長さの最初の 1 回だけ約 6 秒遅い（9.1 秒・12.9 秒） |
| GPU なし（PyTorch の CPU） | 39〜50 秒 | 137〜229 秒 | 2 回測って幅がある |
| （参考）ONNX Runtime の CPU | 154〜159 秒 | 測っていない | PyTorch の CPU より遅いので、採用していない |

- 倍率: GPU なしは CUDA の約 13 倍（2 秒の動き）〜約 20〜30 倍（10 秒の動き）
- DirectML の 3.2 秒のうち、ONNX Runtime の中にいたのは約 2.7 秒（Transformer 2 つ × 100 回）。残りはループ・キーの条件・後処理（PyTorch の CPU）

### MotionBricks（中割り・止まり方。81 フレームを 3 区間で作る依頼）

| 方式 | 1 回の生成 | うち推論 1 回 | エンジンを開くまで |
|---|---|---|---|
| CUDA（TensorRT。0.2.x までと同じ） | 0.41 秒（別の回は 0.30 秒） | 3.0〜4.8 ミリ秒 | 2.7 秒（準備済みの時。初回は GPU ごとに数分） |
| DirectML（ONNX Runtime） | 0.43 秒 | 6.8〜10 ミリ秒 | 3.8 秒（初回だけ、手直しした ONNX を作る数秒が乗る） |
| GPU なし（ONNX Runtime の CPU） | 0.52〜0.56 秒 | 39〜43 ミリ秒 | 2.9 秒 |

- 推論はどの方式もミリ秒で、時間のほとんどは姿勢の詰め替え（Python 側）。**MotionBricks は GPU なしでも体感が変わらない**

## 動きの質（方式による差）

| 比べた物 | 差 |
|---|---|
| Kimodo: DirectML と PyTorch の CPU（同じ乱数の種） | 関節の回転 最大 0.005〜0.006 度・平均 0.0005 度／腰の位置 0.001cm |
| Kimodo: 書き出し用に書き下した計算と、元の計算（倍精度） | 7.0e-15（腰用）・1.2e-12（体用）＝数学的に同じ |
| MotionBricks: DirectML・CPU と TensorRT | 回転 最大 0.026 度（ある依頼）〜0.11 度（別の依頼）／腰の位置 0.02mm |
| MotionBricks: DirectML と CPU | 回転 0.05 度未満 |

- Kimodo の CUDA と、DirectML・CPU は、乱数の出どころ（GPU か CPU か）が違うので、同じ種でも別の動きになる（質が違うのではなく、別のサイコロ）
- MotionBricks の TensorRT との差は、TensorRT が速さのために精度を落とした掛け算（TF32）を使う分

## 使う時の注意

- 「DirectML は CUDA と同じ速さ」は **RTX 3090 での話**。DirectML はグラボのメーカーごとにドライバが違うので、Radeon や Intel で同じ速さが出るかは分からない（動かない可能性もある）
- 「GPU なし」の秒数は Core i7-12700F の値。CPU が違えば変わる
- 伝聞として手元にある報告（こちらでは確かめていない）: GTX 1650（4GB）・メモリ 16GB で 0.2.3 が動いた／GTX 1070 Ti で GPU だと落ち、CPU に計算を振ったら動いた／ONNX で GTX 1070 でも MotionBricks が動いた
- 分かっていない事の一覧は `docs/要検証.md`、仕組みと踏んだ物は `docs/DEVELOPMENT.md` の「計算の方式」
