# 中国語（簡体字）の用語と、訳の書き方（11-22）

中国語版 MMD「MMD932」の時、AIナカワリ は簡体字の中国語で出す（11-22 マスター「日本語モード時は日本語、英語モード時は英語、
中国モード時は中国語」・簡体字）。仕組みは英語と同じ `mmd_ainakawari/i18n.py`。訳の表は `mmd_ainakawari/texts/zh_<元のファイル>.py`
（`TEXT = {日本語の文: 中国語}`。キーは `en_<元のファイル>.py` と同じ日本語の文）、漏れの見張りは `tests/check_i18n.py`（`--lang=zh`）。
書き方の決まり（`_()` で包む・差し込み・`# i18n: skip`）は [英語の用語.md](英語の用語.md) と同じ。

## 中国語の言い回し
- 簡体字。短く、平易に。お願いは「请……」、できたことは「已……」（"已撤销"）、途中は「正在……」（"正在生成…"）。
- 句読点は全角: ，。：；？！（）。UI の項目名やボタンの名前は “” で囲む（日本語の「」の代わり）。区切りの「・」は「、」。
  範囲の「〜」は「～」（"3～40F"）。… はそのまま。
- 単位: フレーム → 帧（数字の後ろの F はそのまま "90F"）、秒 → 秒、cm・GB はそのまま。
- 差し込み `{名前}`・`{sec:.0f}` などは、そのまま残す（名前も書式も変えない）。`\n` も同じ位置に残す。
- **訳さない物**: ボーン・モーフの名前（センター・上半身・左足ＩＫ・全ての親 など。PMX の中の名前なので日本語のまま）、
  Kimodo・MotionBricks・Llama・SOMA・CUDA・DirectML・CPU・GPU・VRAM・PMX・VMD・MMD・MMM・app.log などの固有名・ファイル名。
- MMD の画面の言葉は、中国語版 MMD932 の画面の字に合わせる（下の表。mmd-mcp の `ui_language.LABELS_ZH` が正本）。
