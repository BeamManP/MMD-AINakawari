# 英語の用語と、訳の書き方（11-11）

MMD が英語モード（ヘルプ → English Mode）の時、AIナカワリ も英語で出す。仕組みは `mmd_ainakawari/i18n.py`、
訳の表は `mmd_ainakawari/texts/en_<元のファイル>.py`（`TEXT = {日本語の文: 英語}`）、漏れの見張りは `tests/check_i18n.py`。

## 書き方
- 画面に出る文（窓・ログの窓・知らせの窓・失敗の文・セットアップ）は `_("日本語")` で包む。中身は日本語のまま。
  - 差し込みは `_("PMX が見つかりません: {path}", path=pmx)`。**f-string を `_()` に入れない**（表から引けない）。
    書式つきも同じ（`_("{s:.1f} 秒", s=t)`）。`{` `}` をそのまま出す時は `{{` `}}`。
  - 定数は `N_("…")` で印を付け、使う所で `_(定数)`。
  - 文を `+` でつなぐ・`"・".join` などで組み立てる所は、組み立てた後ではなく部品ごとに包む（区切りの「・」も `_("・")`）。
- 訳さない日本語は、その行の末尾に `# i18n: skip`:
  ボーン・モーフの名前（センター・左つま先など）、MMD・MMM の画面の文字や窓の文（見分けに使う物）、正規表現、ファイルの中身の書式、スレッドの名前。
- `applog.write`・`applog.exception` の記録（開発者が読む物）と、argparse の説明は包まない（確認スクリプトも見ない）。
- 説明の文（docstring）とコメントは日本語のまま。
- 言葉は呼んだ時の `i18n.lang()`。窓（app.py）は自分の言葉を `i18n.use()` で包んでから仕事のスレッドを回すので、
  ほかのファイルは `_()` を呼ぶだけでよい。**新しくスレッドを作る所**は、作る時の `i18n.lang()` を控え、スレッドの中で `with i18n.use(控え):`。
- 英語の表には、そのファイルで包んだ文を全部入れる。差し込みの名前は日本語と同じにする（確認スクリプトが見る）。

## 英語の言い回し
- 短く、平易に。です・ます の丁寧さは英語では命令形・平叙文でよい（"Select a model in MMD", "Install it with Setup below"）。
- 日本語の「〜してください」→ 命令形。「〜しました」→ 過去形 or 名詞止め（"Done", "Cancelled"）。「〜中…」→ "-ing..."（"Generating..."）。
- 全角の括弧（）は半角 ( ) に、「」は "" に、〜 は -（"3-40F"）、・ は ", "。… は ...。
- 単位: フレーム → F（数字の後ろ）か frames、秒 → s（"21 s"）、cm・GB はそのまま。
